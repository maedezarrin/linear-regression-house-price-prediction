# House Price Prediction with Linear Regression (Manual Implementation)

## 📌 Project Overview
This project implements **Linear Regression** from scratch using NumPy to predict house prices based on features like area and number of rooms.

## 🎯 Objectives
- Understand the math behind Linear Regression (OLS formula).
- Implement the model manually using `np.linalg.inv`.
- Evaluate the model using MSE, RMSE, and MAE.

## 🛠️ Tools Used
- **NumPy** and **Pandas** for data processing.
- **Matplotlib** for visualization.

## 📊 Dataset
A real estate dataset containing features like `Area`, `Room`, `Parking`, etc.

## 🔍 Key Results
- The model achieved an RMSE of ~$189,870.
- Adding more features (Room, Parking, etc.) improved the model significantly compared to using only `Area`.

## 📂 Files
- `linear_regression.ipynb`

## 📈 How to Run
1. Clone the repository.
2. Install required libraries: `pip install pandas numpy matplotlib`
3. Run the Jupyter notebook.
